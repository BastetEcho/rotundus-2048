# rotundus-2048

A round 2048 prototype. The square board is remapped around the bottom-left corner into rings of 1, 3, 5, and 7 cells. Move tiles clockwise or counterclockwise around each ring, and drag the radial cut line to choose where each ring starts compressing.

Open `2048.html` in a browser to play. Controls: Left/A for counterclockwise, Right/D for clockwise, U to undo, and N for a new game.
